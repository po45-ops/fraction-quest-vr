# Fraction Quest AR 🐰📷

เกม AR ผ่านกล้องสำหรับฝึก **การเปรียบเทียบเศษส่วนโดยใช้ 1/2 เป็นเกณฑ์** ผู้เล่นใช้มือจริงหน้ากล้องเพื่อหยิบเครื่องหมาย `<`, `=` หรือ `>` แล้ววางระหว่างเศษส่วน

> Repository ยังใช้ชื่อ `fraction-quest-vr` ตามชื่อเดิม แต่ตัวเกมเป็น **Camera AR + Hand Tracking**

## จุดเด่นของเวอร์ชันปัจจุบัน

- หน้าแรกแบบวิดีโอเคลื่อนไหว พร้อมปุ่ม Start / วิธีเล่น / ตั้งค่า / เสียงที่กดได้จริง
- เอฟเฟกต์ปุ่มแบบยุบตัว เรืองแสง ripple และเสียงตอบสนอง
- หน้าเล่นเกมโทนแฟนตาซีสีสดตามงานออกแบบสำหรับเด็ก
- แสดงเศษส่วนแบบตัวเศษอยู่ด้านบน ตัวส่วนอยู่ด้านล่าง
- ปุ่ม `<`, `=` และ `>` แบบสามมิติ พร้อม hover / press / hand-grab feedback
- แสดงคำว่า **ถูก** หรือ **ผิด** อย่างชัดเจนหลังตอบ
- ซ่อนแถบปริมาณระหว่างคิด และแสดงเฉพาะช่วงเฉลยหลังตอบแล้ว
- Hint ให้แนวคิด “เทียบกับ 1/2” โดยไม่เปิดแถบคำตอบล่วงหน้า
- MediaPipe Hands สำหรับ pinch-to-grab และ drag-to-drop
- เล่นด้วยเมาส์หรือหน้าจอสัมผัสได้ หากไม่เปิดกล้อง
- คะแนน ดาว เสียง และเอฟเฟกต์ฉลอง
- Responsive สำหรับคอมพิวเตอร์ แท็บเล็ต และมือถือ

## วิธีเล่น

1. เปิดเกมผ่าน GitHub Pages ด้วย HTTPS
2. กด **เริ่มเกม** แล้วอนุญาตสิทธิ์กล้อง
3. ยกมือขึ้นหน้ากล้อง
4. จีบนิ้วโป้งกับนิ้วชี้เหนือเครื่องหมาย `<`, `=` หรือ `>`
5. ลากไปยังช่องกลาง แล้วคลายนิ้วเพื่อวางคำตอบ
6. อ่านผล **ถูก / ผิด** และดูภาพเฉลยที่เทียบแต่ละเศษส่วนกับ `1/2`

หากไม่สะดวกใช้กล้อง ให้เลือก **เล่นด้วยเมาส์ / หน้าจอสัมผัส**

## การประมวลผลกล้อง

วิดีโอจากกล้องใช้สำหรับตรวจจับตำแหน่งมือภายในเบราว์เซอร์เท่านั้น โค้ดเกมไม่มีการบันทึกหรืออัปโหลดวิดีโอ

## เล่นบนเครื่อง

```bash
python3 -m http.server 8080
```

จากนั้นเปิด `http://localhost:8080`

> การเปิดกล้องบน deployment จริงต้องใช้ HTTPS ซึ่ง GitHub Pages รองรับ
